# QML-CNN-Welds

QML-CNN-Welds presents a compact research codebase for image-classification experiments inspired by TIG weld-defect detection. The retained implementation centers on a classical convolutional neural network baseline, with an optional hybrid quantum-classical model path for PennyLane-based experimentation.

The repository is a project showcase for the modeling pipeline, not a production inspection system. The default executable path uses the scikit-learn digits dataset as a compact image-classification proxy; weld imagery and dataset-bound Kaggle artifacts are not versioned.

## Repository Contents

- `src/qml_cnn_welds/` - data loading, model definitions, training utilities, and evaluation entry points.
- `configs/` - baseline configuration for the compact CNN run.
- `scripts/` - command-line entry points for the demo run and generated metrics.
- `docs/` - project overview, methodology, limitations, and lineage notes.
- `tests/` - smoke tests for imports, data loading, and the default training path.
- `results/` - local output target for generated metrics.

## Technical Scope

- Classical CNN baseline for compact grayscale image classification.
- Optional hybrid quantum-classical model skeleton using PennyLane.
- CPU-friendly training path on a small public proxy dataset.
- No proprietary weld imagery, challenge datasets, Kaggle caches, model checkpoints, or generated bytecode.
- No claim of quantum advantage, state-of-the-art performance, or deployment readiness.

## Project Lineage

The project grew out of Womanium Quantum+AI weld-classification experiments around TIG weld imagery, classical CNN baselines, and hybrid quantum-classical model ideas. The public package keeps the defensible modeling structure while avoiding dataset-bound notebooks, challenge boilerplate, and local-environment artifacts.

Additional notes are in [docs/project_lineage.md](docs/project_lineage.md).
